# DS323 — AI in Design: Course Materials

This repository is the materials-only workspace for DS323 — AI in Design. It is separate from the private course-page authoring repository, `DS323_asTeach`.

## Offerings

- [2023 Autumn](2023-autumn/README.md) — course PDFs and supporting images
- [2022 Autumn](2022-autumn/README.md) — course PDFs, student demonstrations and supporting images

The reviewed course materials are stored by offering in `2023-autumn/` and `2022-autumn/`. PDFs and videos retain their original filenames. Supporting images use descriptive course-specific filenames. This repository remains private; these links require repository access until a separately approved public release. Third-party materials retain their original authorship and rights; no blanket license is granted over their contents.

The private course review is being prepared using [asTeach App v0.1](https://github.com/ancorasir/asTeach-App/releases/tag/v0.1). This repository does not contain Teacher preparation, GitBook configuration or private development records.
