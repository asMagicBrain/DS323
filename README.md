# DS323 — AI in Design

DS323 builds a bridge between design and artificial intelligence. The course
introduces machine learning, deep learning, data and the design process, helping
design students shape AI-powered products and services within human contexts.
Through applied design projects, students explore how AI can create user,
business and social value, align systems with human needs and values, and
communicate and collaborate with AI scientists and engineers.

## Maintaining the Course

- Use the GitBook course page as the student-facing reference for each term.
  This repository stores downloadable materials, not the private authoring workspace.
- Add or replace materials in the matching `YYYY-season/` folder, then update
  the corresponding course links. Retain existing filenames when replacing a
  file so that its links continue to work.
- Edit course content in the private authoring workspace and review the matching
  student-facing page before publishing an update. Changes to course text and
  GitHub materials are separate steps; adding a file here does not update the
  course page automatically.
- Keep instructor preparation, answers, credentials and protected student records
  out of this public repository.
